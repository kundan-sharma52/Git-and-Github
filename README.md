# Student Record Management System

A console-based Python 3 program to manage student records (roll number, name, course, marks).

## Features

- Add a new student
- View all students in a table
- Search a student by roll number
- Update marks
- Delete a student
- Roll numbers are unique and marks must be between 0 and 100

## Concepts Used

Lists, Tuples, Dictionaries, Functions, CRUD operations

## How to Run

1. Install Python 3
2. Download `studentRecords.py`
3. Open the console in that folder and run:

```
python studentRecords.py
```

## Sample Menu

```
1. Add Student
2. View Students
3. Search Student
4. Update Marks
5. Delete Student
6. Exit
```
